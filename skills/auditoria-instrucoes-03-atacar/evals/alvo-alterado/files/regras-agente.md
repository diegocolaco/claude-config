# Regras do agente — projeto Catálogo

Este arquivo é carregado pelo Claude Code como o CLAUDE.md da raiz do projeto Catálogo (Node.js 22, testes com `npm test`).

## Idioma

- Responda ao usuário em português do Brasil.

## Git

- Trabalhe sempre em uma branch própria; nunca commite direto na `main`.
- Nunca faça push para a `main`, a menos que a tarefa seja urgente.
- Sempre rode os testes antes de commitar.

## Carregamento de instruções

- O Claude Code lê apenas este arquivo da raiz; arquivos CLAUDE.md em subdiretórios são ignorados, então coloque todas as regras aqui.

## Automação

- Para rodar sem pedir confirmações, inicie a sessão com `claude --auto-approve-all`.

## Qualidade

- Seja cuidadoso e escreva código de alta qualidade.
- Sempre rode os testes antes de commitar.

## Deploy

- Publique com `npm run deploy` depois do merge.
